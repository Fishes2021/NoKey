# 自定义语音快捷键

Mac → 设置 → 语音快捷键。选择输入法已有的主键和修饰键，保存即可；NoKey 不会修改系统或输入法的快捷键。默认保留右 Option。

支持普通单键、左／右 Option、Control、Shift、Command 单独按下，以及 Command／Control／Option／Shift 与普通主键组合。左右修饰键单键不能再叠加修饰键；Fn／地球键、双击和按住讲话不在首版支持范围内。触发模式为按一次开始、再按一次结束。

高级项“结束后发送延迟”默认为350毫秒，可设0–3000毫秒。不同输入法处理最后一句的时间不同；这只是等待时间，不是识别完成确认。

保存后下次讲话生效，不用退出 NoKey。当前讲话固定使用开始时的配置，结束或断线收尾最多投递一次结束按键；输入目标／权限变化或结果不确定时不重发，不继续自动提交。控制端只记按键投递状态，不能读取所有输入法的内部听写状态；电脑上手动切换听写可能让状态不一致。

测试：将 Mac 光标放到测试输入框，用手机开始／结束各一次；再测试讲话时发送，确认尾句完整。慢速输入法可增大发送延迟。请两端一同更新；新版手机不会向旧 Mac 降级发送写死的右 Option，只提示更新。

配置仅保存在该 Mac 的客户端数据目录 dictation.json，权限0600、原子保存。全程没有新增全局键盘监听或系统权限。后台停止采音和自动选路逻辑沿用原实现。
