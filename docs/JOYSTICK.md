# 摇杆与快捷配置

- 保留面板样式。摇杆默认发送上、右、下、左方向键；中心区域不发送，长按在首次确认后等待350毫秒，再每次确认后等待90毫秒重复。松手、失联或切后台停止；已发出的单次按键无法撤回。
- 自定义入口在设置中。只有不带修饰键的方向键重复，其他自定义动作每次拨动执行一次；旋钮点按不再发送回车。
- 快捷布局由已配对的Mac保存，同一Mac的手机共享一套布局。设置保存先取得Mac确认，重装手机或重新配对后恢复。卸载Mac时若同时删除其数据目录，布局也会丢失。
- 首次更新从现存手机缓存迁移。旧版已丢失且没有备份的配置无法追回；无标签的历史回车摇杆配置恢复成方向键，明确命名的自定义回车保留。
- 配置接口复用既有加密配对和控制会话认证；版本冲突拒绝覆盖，重新打开快捷设置同步。两端须一起更新，旧Mac不提供配置接口。

验证：方向重复/释放、配置校验/持久化、真实加密重新配对恢复及发送回归见相关test文件。真实触感与长时间语音仍需设备使用验证。
