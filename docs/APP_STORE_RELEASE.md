3. iOS 自有开发团队与 App Store Connect 应用记录、分发签名、归档上传及外部测试审核。
4. Mac Developer ID 签名、公证和最终包检查。
5. 二进制内完整第三方许可证、素材清单及 GPL 源码对应关系；App Store 分发条件须在提交前单独核对，开源仓库发布不代表商店分发条件已满足。

付费会员、服务器、域名、商店提交均不由构建脚本自动开通。代码不提供可直接复用的他人签名或 App Store ID。
