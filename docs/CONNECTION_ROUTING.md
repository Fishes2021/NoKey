# 一次配对，自动选路

手机只保存一套 Mac 配对身份。Mac 只显示一个二维码，携带可用的局域网地址和已配置的中继地址；请使用 NoKey 内置扫码器，异网时不要依赖系统相机打开局域网网页。

- 配对前通过加密探针验证同一台 Mac，仅向选中的通道提交一次配对申请，Mac 只需确认一次。
- 局域网先尝试，250 毫秒后同时尝试中继；首条通过身份验证的通道获选。连接正常时保持，不逐条请求测速。
- 前台恢复、网络类型变化或通道失败时重新选择。Mac 在运行期间通过 Bonjour 发布本机服务，手机仅在选路时短暂发现，找到的地址仍须通过配对密钥验证。
- 后台停止轮询、发现和重连，同时停止采音；前台恢复只检查连接，不自动讲话。
- 查询可换路重试；文字、按键、发送、讲话操作不自动重发。失去回执时提示结果未确认，由用户判断是否再次操作。
- 中继服务停机、未激活或到期不影响可达的局域网。中继地址及设备身份由 Mac 配置，手机通过认证响应学习更新，无需为第二条通道再次配对。
- 音频仍使用 WebRTC / ICE 传输；信令换路不等于把音频复制发送两遍。网络切换可能短暂中断，不能承诺无缝语音。

## 兼容与验收

已有配对在原地址成功连接后会学习候选地址。若旧地址已不可达且手机没有候选地址缓存，请更新两端后重新扫码一次。后续无需局域网／异网分别配对。

新二维码的异网配对探针需要中继服务同步支持 `/api/e2ee/pair-probe`。仅更新客户端不会更新服务器；目前公网域名受备案拦截，云端升级与蜂窝网络验收待备案完成。

本机检查：真实加密桥接验证单次配对、LAN/中继选路、错误身份拒绝、动作回执丢失不重发；后台晚响应不恢复连接；原生 Mac Bonjour 广播可解析。构建成功不代替 iPhone 的本地网络授权、切 Wi-Fi／蜂窝和连续语音真机验收。
